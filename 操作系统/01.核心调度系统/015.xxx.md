# 一多 OS 运行 Wasm 组件：基于 Wasmtime/WasmEdge 的技术方案

## 🎯 核心洞见

### 💡 革命性观点：Wasmtime 本身也是一多 OS 的一个组件！

**不是一多 OS 包含 Wasmtime，而是 Wasmtime 是一多 OS 组件生态系统中的一个组件！**

这完全符合一多 OS"一切皆组件"的哲学：

| 组件类型      | 例子                | 说明        |
| --------- | ----------------- | --------- |
| **应用组件**  | 用户开发的 Wasm 应用     | 最终用户看到的部分 |
| **工具组件**  | IDE、编译器、调试器       | 开发工具链     |
| **运行时组件** | Wasmtime、WasmEdge | 核心执行引擎    |
| **能力组件**  | 摄像头、音频、网络         | 系统能力接口    |

***

## 🎯 核心结论

**一多 OS 不需要自己写 Wasm 虚拟机！而是把 Wasmtime/WasmEdge 作为组件集成到生态中。**

***

### 为什么完全可行？

| 维度                    | 说明                                   | 成熟度    |

## 🏗️ 一多 OS 的 Wasm 运行架构

### 总体架构

```
用户命令：yiduo run cmd.wasm
    ↓
一多 OS CLI (MoonBit/Rust 编写) ← 我们需要写的部分
    ↓
一多 OS 增值层（组件编排、健康检查、多后端调度）
    ↓
Wasmtime/WasmEdge (底层 Wasm 运行时) ← 白嫖！
    ↓
操作系统 (Linux/Windows/macOS)
```

### 阶段一：MVP（0-3个月）- 简单包装器

**目标：让一多 OS 能运行 Wasm，同时提供配置驱动和组件编排能力**

```
┌─────────────────────────────────────────────────┐
│  用户：yiduo run --config app.yaml cmd.wasm      │
└───────────────────┬─────────────────────────────┘
                    │
┌───────────────────▼─────────────────────────────┐
│  一多 OS CLI (Rust 编写)                         │
│  1. 解析 YAML 配置                               │
│  2. 检查依赖关系                                 │
│  3. 健康监控钩子                                 │
│  4. 调用 wasmtime CLI                           │
└───────────────────┬─────────────────────────────┘
                    │
┌───────────────────▼─────────────────────────────┐
│  Wasmtime CLI (外部进程)                         │
│  wasmtime --dir=. cmd.wasm                      │
└─────────────────────────────────────────────────┘
```

#### 代码示例（Rust CLI）

```rust
// src/main.rs
use clap::Parser;
use std::process::Command;
use std::fs;

#[derive(Parser, Debug)]
#[command(author, version, about, long_about = None)]
struct Args {
    /// Wasm 文件路径
    wasm_path: String,
    
    /// 一多 OS 配置文件（可选）
    #[arg(short, long)]
    config: Option<String>,
    
    /// 开启详细日志
    #[arg(short, long)]
    verbose: bool,
}

fn main() -> anyhow::Result<()> {
    let args = Args::parse();
    
    if args.verbose {
        println!("一多 OS Wasm 运行时启动");
    }
    
    // 1. 解析配置（如果有）
    if let Some(config_path) = &args.config {
        if args.verbose {
            println!("加载配置: {}", config_path);
        }
        let config = fs::read_to_string(config_path)?;
        // 解析 YAML，进行组件编排...
    }
    
    // 2. 调用 Wasmtime 执行
    if args.verbose {
        println!("执行 Wasm: {}", args.wasm_path);
    }
    
    let status = Command::new("wasmtime")
        .arg("--dir=.")
        .arg(&args.wasm_path)
        .status()?;
    
    if !status.success() {
        anyhow::bail!("Wasm 执行失败");
    }
    
    Ok(())
}
```

```rust
use wasmtime::*;
use std::path::Path;

pub struct YiduoRuntime {
    engine: Engine,
    linker: Linker<()>,
}

impl YiduoRuntime {
    pub fn new() -> Result<Self> {
        // 1. 初始化 Wasmtime

        let mut linker = Linker::new(&engine);

        wasmtime_wasi::add_to_linker(&mut linker, |s| s)?;
        
        // 3. 添加一多 OS 自定义接口
        self.add_yiduo_capabilities(&mut linker)?;
        
        Ok(Self { engine, linker })
    }
    
    fn add_yiduo_capabilities(&self, linker: &mut Linker<()>) -> Result<()> {
        // 添加一多 OS 的能力（摄像头、音频等）
        // 通过 WIT 定义和后端适配器
        Ok(())
    }
    
    pub fn run_wasm<P: AsRef<Path>>(&self, wasm_path: P, config: YiduoConfig) -> Result<()> {
        let mut store = Store::new(&self.engine, ());
        
        // 1. 加载 Wasm 模块
        let module = Module::from_file(&self.engine, wasm_path)?;
        
        // 2. 一多 OS 增值逻辑：组件编排
        let component_tree = self.build_component_tree(&config)?;
        
        // 3. 一多 OS 增值逻辑：健康检查
        self.health_check(&component_tree)?;
        
        // 4. 实例化并运行
        let instance = self.linker.instantiate(&mut store, &module)?;
        
        // 5. 调用入口函数
        let run_func = instance.get_typed_func::<(), ()>(&mut store, "_start")?;
        run_func.call(&mut store, ())?;
        
        Ok(())
    }
}
```

## 📚 技术选型详情

### 为什么选择 Wasmtime？

| 特性          | 说明                    | 优势           |
| ----------- | --------------------- | ------------ |
| **官方标准**    | Bytecode Alliance 主导  | 规范引领，长期稳定    |
| **高性能**     | 接近原生速度                | 满足性能要求       |
| **Rust 生态** | 用 Rust 编写             | 与一多 OS 技术栈一致 |
| **WASI 支持** | Preview 2 已稳定         | 可直接使用        |
| **生产验证**    | Fastly、Cloudflare 等采用 | 证明可靠         |

### 为什么也可以支持 WasmEdge？

| 特性          | 说明                            | 优势       |
| ----------- | ----------------------------- | -------- |
| **AI 优化**   | 内置 TensorFlow Lite、PyTorch 支持 | 适合 AI 场景 |
| **轻量级**     | 更小的体积                         | 适合边缘设备   |
| **WASI-NN** | 神经网络标准                        | 面向未来     |

**一多 OS 策略：**

- 默认：Wasmtime
- 选项：WasmEdge（通过配置选择）

```yaml
components:
  - name: main

    path: ./main.wasm

    type: wasm
```

```bash
yiduo run --config app.yaml
```

