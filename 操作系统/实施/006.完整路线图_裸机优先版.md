| 阶段 | 目标 | 预计时间 | 状态 |

## 🎯 阶段 0：最小内核（裸机启动！）—— 3-4 周

**目标：一多 OS 在 ESP32-C3 上裸机上电启动，有 UART 输出！**

**这是第一优先！**

### 任务清单

| ID | 任务 | 说明 | 预计时间 |
|----|------|------|------|
| T0.1 | 环境搭建 | ESP-IDF + MoonBit 工具链 | 2 天 |
| T0.2 | 启动引导代码 | 利用 ESP-IDF，适配 MoonBit | 3 天 |
| T0.3 | 最小硬件初始化 | 时钟、内存、UART | 3 天 |
| T0.4 | MoonBit Native 运行时初始化 | 让 MoonBit 在裸机上跑起来 | 2 天 |
| T0.5 | 调度器核心移植 | 把现有的 scheduler.mbt 移植到裸机 | 3 天 |
| T0.6 | 简单配置解析器 | 硬编码或简单格式 | 2 天 |
| T0.7 | Flash 简单读取 | 读取配置数据 | 3 天 |
| T0.8 | 完整启动流程测试 | 端到端测试 | 3 天 |

### 交付物
- ✅ 可以烧录到 ESP32-C3 的固件
- ✅ 上电启动有 UART 输出："一多 OS 启动成功！"
- ✅ 调度器运行
- ✅ 从 Flash 读取简单配置
- ✅ **不需要 Linux/Windows 或其他 OS！**

### 验收标准
1. 可以编译固件并烧录
2. 上电启动有 UART 输出
3. 输出包含 "一多 OS 启动成功！"
4. 调度器可以运行
5. 完全裸机，不依赖其他 OS

## 🏗️ 技术架构（裸机版）

```
┌─────────────────────────────────────────────────────────────┐
│                  用户应用层（Wasm 组件）                     │
├─────────────────────────────────────────────────────────────┤

│  ┌───────────────────────────────────────────────────────┐  │
│  │ 配置解析 │ 组件加载 │ 智能调度 │ 消息总线             │  │
│  └───────────────────────────────────────────────────────┘  │
├─────────────────────────────────────────────────────────────┤
│              一多 OS 最小内核（MoonBit Native）             │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ 内存管理 │ 简单任务调度 │ 中断处理                     │  │
│  └───────────────────────────────────────────────────────┘  │
├─────────────────────────────────────────────────────────────┤
│               硬件抽象层 HAL（Rust/C）                      │
│  ┌───────────────────────────────────────────────────────┐  │
│  │ 启动引导 │ UART 驱动 │ Flash 驱动 │ （更多驱动...）    │  │
│  └───────────────────────────────────────────────────────┘  │
├─────────────────────────────────────────────────────────────┤
│                      裸机硬件（ESP32-C3）                     │
└─────────────────────────────────────────────────────────────┘
```

### 关键实现策略

| 层次 | 语言 | 说明 |
|------|------|------|
| **内核核心** | MoonBit Native | 调度器、配置解析、组件加载 |
| **HAL 层** | Rust/C | 硬件驱动、启动引导、FFI 桥接 |
| **应用组件** | Wasm | 用户应用、文件系统等功能 |

## 📂 建议的项目结构

```
yiduo/
├── src/                    # MoonBit 内核代码（已存在）
│   ├── scheduler/
│   ├── core/
│   └── bootstrap.mbt
├── kernel/                 # 新：裸机内核代码
│   ├── boot/               # 启动代码（ESP-IDF 适配）
│   ├── hal/                # Rust/C HAL 层
│   └── moonbit-adapter/    # MoonBit ↔ HAL FFI 桥接
├── components/             # Wasm 组件
├── interfaces/             # WIT 接口
└── 操作系统/               # 文档
```

## 🎯 立即开始的第一步

### 今天就可以做的事：

1. **准备硬件**：购买 ESP32-C3 开发板（如果还没有）

3. **验证示例**：运行 moonbit-esp32 的 Hello World 示例
4. **烧录测试**：验证可以烧录到开发板并看到 UART 输出
