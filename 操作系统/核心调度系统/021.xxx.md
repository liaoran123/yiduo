# 一多 OS MVP：详细实施步骤指南

## 📋 概述

本文档提供从 0 开始完整实施一多 OS MVP 的详细步骤。由于当前环境可能没有完整的 Rust/Wasm 工具链，本指南将所有文件都准备好，你可以直接在有工具的环境下按步骤执行。

## 🎯 前提条件

请在你的开发机器上安装以下工具：

| 工具 | 作用 | 安装链接 |
|------|------|---------|
| **Rust** (包含 cargo) | 编译 Rust 代码为 Wasm | https://rustup.rs/ |
| **MoonBit** | 一多 OS 主要编程语言 | https://www.moonbitlang.com/ |
| **wit-bindgen-cli** | 从 WIT 生成语言绑定 | https://github.com/bytecodealliance/wit-bindgen |
| **wasm-tools** | Wasm 组件转换工具 | https://github.com/bytecodealliance/wasm-tools |
| **Wasmtime** | Wasm 组件运行时 | https://wasmtime.dev/ |

验证安装：

```bash
rustc --version
cargo --version
wit-bindgen --version
wasm-tools --version
wasmtime --version
```

## 🚀 实施步骤（当前环境可能需要在有工具的机器上执行）

### 第 1 步：生成 Rust 绑定代码

在 `components/impl/rust-hello` 目录下执行：

```bash
cd d:\yiduo\components\impl\rust-hello
wit-bindgen rust ../../../interfaces/base/hello.wit --out-dir src
```

这将在 `src` 目录下生成 `bindings.rs` 等绑定代码。

---

### 第 2 步：编译 Rust 为 Wasm

```bash
# 添加 WASI 目标（如果没有的话）
rustup target add wasm32-wasip1

# 编译
cargo build --target wasm32-wasip1 --release
```

成功后，会在 `target/wasm32-wasip1/release` 目录下生成 `rust_hello.wasm`。

---

### 第 3 步：转换为标准 Wasm Component

```bash
cd d:\yiduo\components\impl\rust-hello

# 第一步：嵌入 WIT 信息
wasm-tools component embed ../../../interfaces/base/hello.wit target/wasm32-wasip1/release/rust_hello.wasm -o hello_world.embed.wasm

# 第二步：转换为 Component
wasm-tools component new hello_world.embed.wasm -o ../../hello-world.wasm
```

成功后，会在 `components` 目录下生成 `hello-world.wasm`。

---

### 第 4 步：测试 Wasm 组件

```bash
cd d:\yiduo\components
wasmtime run hello-world.wasm
```

预期输出：

```
Hello, ...! 欢迎来到一多 OS！
```
