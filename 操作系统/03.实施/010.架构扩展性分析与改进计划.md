## ✅ 核心架构无需重构的部分

### 1. 调度器核心架构 [scheduler.mbt](file:///d:/yiduo/runtime/scheduler/scheduler.mbt)

**当前设计**：
```moonbit
struct Scheduler {
  high_queue: RingBuffer<Message>
  normal_queue: RingBuffer<Message>
  low_queue: RingBuffer<Message>
  pool: MemoryPool
  components: FixedArray[Option[ComponentInfo]]
  max_components: Int
  is_running: Bool
}
```

**扩展性分析**：🟢 很好
- FixedArray 索引访问，性能好，可扩展
- ComponentInfo 是 Option 类型，可扩展字段
- 三级优先级队列设计灵活

**建议**：无需重构，保持不变

## 🎯 关键架构改进建议（不是重构，是补充）

### 补充 1：能力匹配机制

在 [scheduler.mbt](file:///d:/yiduo/runtime/scheduler/scheduler.mbt) 中新增：
```moonbit
// 新增：按能力查找组件
fn find_component_by_capability(
  self: Scheduler,
  capability: String
) -> Option<Int> {
  let mut i = 0
  while i < self.max_components {
    match self.components[i] {
      Some(comp) => {
        if comp.capabilities.contains(capability) {
          return Some(i)
        }
      }
      None => {}
    }
    i = i + 1
  }
  None
}

// 新增：按能力发送消息
fn send_by_capability(
  self: Scheduler,
  from: Int,
  capability: String,
  msg: Message,
  priority: MessagePriority
) -> (Scheduler, Bool) {
  match self.find_component_by_capability(capability) {
    Some(to_id) => self.send_message(from, to_id, msg, priority),
    None => (self, false)
  }
}
```
