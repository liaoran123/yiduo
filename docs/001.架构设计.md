# 一多 OS 架构设计文档

## 核心架构：四元哲学

一多 OS 的设计围绕四个核心概念展开，每个概念对应具体的技术实现：

| 哲学概念 | 技术映射 | 代码实现 |
|---------|---------|---------|
| **意志（配置文件）** | 用户的声明式意图 | [bootstrap.yaml](../configs/bootstrap.yaml) |
| **DNA（组件）** | 系统的基本单元 | [ComponentInfo](../src/scheduler/scheduler.mbt#L14-L20) |
| **树形（配置层级）** | 配置的层次结构 | [AppConfig → Spec → ComponentConfig](../src/config/config_loader.mbt#L33-L38) |
| **链式（组件通信）** | 组件间的消息传递 | [Message 三种模式](../src/core/message.mbt#L24-L44) |

## 核心数据结构

### 消息系统（三种模式）

```
 Message (enum)
 ├── SmallMessage { from, to, payload }    ← 复制模式（安全优先）
 │    适用: 配置命令、事件通知、控制信号
 │    性能: ~3ns (入队)
 │
 ├── MediumMessage { from, to, handle }     ← 句柄模式（平衡）
 │    适用: 传感器数据、网络包
 │    性能: ~5ns (仅移动句柄)
 │
 └── LargeMessage { from, to, handle, mode } ← 共享内存（性能优先）
      适用: 图像缓冲、大文件
      性能: ~3ns (零拷贝)
```

### 优先级队列

```
 高优队列 (High Priority)   → 容量 64
 普通队列 (Normal Priority) → 容量 256
 低优队列 (Low Priority)    → 容量 128
```

### 组件注册表

```
 FixedArray[Option[ComponentInfo]] (32 槽位)
 ├── [0]: Some(ComponentInfo)  ← 日志服务 (native)
 ├── [1]: Some(ComponentInfo)  ← 计数器 (wasm)
 ├── [2]: Some(ComponentInfo)  ← 显示器 (wasm)
 ├── [3]: None                 ← 空闲
 └── ...
```

## 性能架构

我们采用了三层性能优化策略：

### 第一层：语言层面（MoonBit 内置）

| 特性 | 说明 | 受益代码 |
|------|------|---------|
| **值类型** | 结构体存储在栈上，避免堆分配 | [MemoryBlock](../src/core/memory_pool.mbt#L5-L9)、[ComponentInfo](../src/scheduler/scheduler.mbt#L14-L20) |
| **Native 编译** | 直接编译为机器码，不需要 VM | 所有代码 |

### 第二层：数据结构优化（我们做的）

| 优化 | 前 | 后 | 提升 |
|------|---|----|------|
| **组件表** | `Map[String, ComponentInfo]` | `FixedArray[Option[ComponentInfo]]` | ~50x |
| **内存池** | `Map[String, MemoryBlock]` | `FixedArray[MemoryBlock]` + 栈 | ~10x |
| **环形队列** | `FixedArray[Option[T]]` | `FixedArray[T]` (无装箱) | ~4x |

### 第三层：混合架构（未来）

```
 MoonBit 调度核心 (90% 代码，90% C 性能)
   +
 Rust/C 硬件驱动 (10% 代码，100% 性能)
   =
 整体 ~95% C 语言性能
```

## 数据流

```
 启动流程:
   1. 加载配置 (bootstrap.yaml)
   2. 初始化调度器 (create_scheduler)
   3. 注册组件 (register)
   4. 发送测试消息 (send_small/medium/large)
   5. 启动调度循环 (run_loop)
      ├── dequeue(高优队列)
      ├── dequeue(普通队列)  ← 如果高优队列为空
      ├── dequeue(低优队列)  ← 如果普通队列也为空
      └── dispatch → 目标组件

 消息生命周期:
   发送方 → enqueue → RingBuffer → dequeue → 调度器 → dispatch → 接收方
                                                       │
                                                   release block (句柄模式)
```
