## 🏗️ 架构特色

### 四元架构

1. **意志**（配置文件）- 系统的最高指令
2. **DNA**（计算细胞）- 功能的遗传代码
3. **生长路径**（树形架构）- 进化的路径
4. **血液系统**（链式架构）- 能量与信息的流动

### 技术特色

- 基于 Wasm Component Model 的跨语言能力
- UniHAL 统一硬件抽象层
- Mock 优先的开发模式
- 配置驱动的系统演化
