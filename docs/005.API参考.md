# API 参考文档

## Scheduler API（双模运行时更新）

| 函数 | 签名 | 说明 |
|------|------|------|
| `create()` | `() -> Scheduler` | 创建默认调度器（32槽，batch=8） |
| `create_with_config` | `(MemoryManager, Int, Int) -> Scheduler` | 创建完整配置调度器 |
| `set_debug_log` | `(Scheduler, Bool) -> Scheduler` | 设置调试日志开关 |
| `register` | `(Scheduler, ComponentInfo) -> (Scheduler, Int)` | 注册组件（ID 从 1 分配） |
| `register_handler` | `(Scheduler, Int, NativeMessageHandler) -> Scheduler` | **双模**：注册 Native 处理器 |
| `send_small` | `(Scheduler, Int, Int, SmallPayload, MessagePriority) -> (Scheduler, Bool)` | 发送小消息 |
| `send_medium` | `(Scheduler, Int, Int, Int, MessagePriority) -> (Scheduler, Bool)` | 发送中消息 |
| `send_large` | `(Scheduler, Int, Int, Int, String, MessagePriority) -> (Scheduler, Bool)` | 发送大消息 |
| `send_message` | `(Scheduler, Int, Int, Message, MessagePriority) -> (Scheduler, Bool)` | 发送通用消息 |
| `process_one` | `(Scheduler) -> Scheduler` | 处理一条消息（高→普通→低） |
| `dispatch` | `(Scheduler, Message) -> Scheduler` | 根据 ComponentType 分发消息 |
| `run_loop` | `(Scheduler, Int) -> Scheduler` | 运行调度循环 |
| `high_queue_length` | `(Scheduler) -> Int` | 高优队列长度 |
| `normal_queue_length` | `(Scheduler) -> Int` | 普通队列长度 |
| `low_queue_length` | `(Scheduler) -> Int` | 低优队列长度 |
| `component_count` | `(Scheduler) -> Int` | 组件数量 |

### ComponentType 枚举（双模运行时）

```moonbit
pub enum ComponentType {
  Native   // 本地直接执行
  Wasm     // Wasm 沙箱隔离（预留）
  MoonBit  // 预留接口
}
```

| 函数 | 说明 |
|------|------|
| `ComponentType::native()` | 创建 Native 类型 |
| `ComponentType::wasm()` | 创建 Wasm 类型 |
| `ComponentType::moonbit()` | 创建 MoonBit 类型 |
| `ComponentType::to_string()` | 转小写字符串 |
| `ComponentType::to_int()` | 转整数（0=Native, 1=Wasm, 2=MoonBit） |
| `ComponentType::from_string(s)` | 从字符串解析（返回 `Option`） |

### NativeMessageHandler 类型（双模运行时）

```moonbit
/// Native 组件消息处理函数签名
/// 参数：(comp_id, from_id, payload)
pub type NativeMessageHandler = (Int, Int, SmallPayload) -> Unit
```

### HandlerRegistry API（双模运行时）

| 函数 | 说明 |
|------|------|
| `HandlerRegistry::create(max_handlers)` | 创建处理器注册表 |
| `registry.register_handler(comp_id, handler)` | 注册组件处理器 |
| `registry.get_handler(comp_id)` | 获取处理器（返回 `Option`） |
| `registry.invoke(comp_id, from_id, payload)` | 调用处理器（返回 Bool） |
| `registry.unregister(comp_id)` | 解注册处理器 |

### WasmRuntime API（Wasm 执行引擎）

```moonbit
pub struct WasmRuntime {
  invoke     : (Int, Int, SmallPayload) -> Unit  // 调用组件处理器
  register   : (Int, NativeMessageHandler) -> Unit  // 注册模拟处理器
  deallocate : (Int) -> Unit  // 释放组件资源
}
```

| 函数 | 说明 |
|------|------|
| `WasmRuntime::create_simulated(max_handlers)` | 创建模拟 Wasm 运行时（同进程 Native 回调） |
| `scheduler.set_wasm_runtime(rt)` | 将 WasmRuntime 注入 Scheduler |
| `scheduler.register_wasm_handler(comp_id, handler)` | 向 WasmRuntime 注册模拟处理器 |


## MemoryPool API

### create(config)
**说明**: 创建内存池

**参数**:
- `config`: `MemoryPoolConfig` - 配置（块大小和块数量）

**返回**: `MemoryPool`

---

### allocate(memory_pool)
**说明**: 从池分配一个块

**返回**: `(MemoryPool, Option[Int])` - (新池, 块ID或None)

---

### retain(memory_pool, id)
**说明**: 增加块的引用计数

**返回**: `MemoryPool`

---

### release(memory_pool, id)
**说明**: 释放块（引用计数减1，归零回收）

**返回**: `MemoryPool`

---

### free_count(memory_pool)
**说明**: 当前空闲块数量

**返回**: `Int`

---

### allocated_count(memory_pool)
**说明**: 已分配块数量

**返回**: `Int`

---

## RingBuffer API

### create(capacity, default)
**说明**: 创建环形队列

**参数**:
- `capacity`: `Int` - 容量（实际可用capacity-1）
- `default`: `T` - 默认值（预填充用）

**返回**: `RingBuffer[T]`

---

### enqueue(ring_buffer, item)
**说明**: 入队

**返回**: `(RingBuffer[T], Bool)` - (新队列, 是否成功)

---

### dequeue(ring_buffer)
**说明**: 出队

**返回**: `(RingBuffer[T], Option[T])` - (新队列, 项或None)

---

### peek(ring_buffer)
**说明**: 查看队首但不取出

**返回**: `Option[T]`

---

### length(ring_buffer)
**说明**: 当前长度

**返回**: `Int`

---

### is_empty(ring_buffer)
**说明**: 是否为空

**返回**: `Bool`

---

### capacity(ring_buffer)
**说明**: 队列容量

**返回**: `Int`

---

### Message（三种消息模式）

```moonbit
enum Message {
  SmallMessage(Int, Int, SmallPayload)       // 小消息：直接从固定 struct 拷贝
  MediumMessage(Int, Int, Int, Bool)         // 中消息：(from, to, handle, auto_free)
  LargeMessage(Int, Int, Int, String, Bool)  // 大消息：(from, to, handle, access_mode, auto_free)
}
```

| 模式 | 内存 | 拷贝方式 | 适用场景 |
|------|------|---------|---------|
| **SmallMessage** | 栈上 | 值拷贝 | 控制指令、元数据（≤ 64B） |
| **MediumMessage** | 堆上 | 句柄转移 | 中等数据块 |
| **LargeMessage** | 堆上 | 共享内存 | 大数据集、流数据 |
