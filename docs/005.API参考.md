# API 参考文档

## Scheduler API

### create()
**说明**: 创建新的调度器实例

**返回**: `Scheduler`

---

### register(scheduler, component_info)
**说明**: 注册组件，返回新调度器和分配的 Int ID

**参数**:
- `scheduler`: `Scheduler` - 当前调度器
- `component_info`: `ComponentInfo` - 组件信息

**返回**: `(Scheduler, Int)`

---

### send_small(scheduler, from, to, payload, priority)
**说明**: 发送小消息（复制模式）

**参数**:
- `scheduler`: `Scheduler`
- `from`: `Int` - 发送方 ID
- `to`: `Int` - 接收方 ID
- `payload`: `SmallPayload` - 消息负载
- `priority`: `MessagePriority` - 优先级

**返回**: `(Scheduler, Bool)` - (新调度器, 是否成功)

---

### send_medium(scheduler, from, to, handle, priority)
**说明**: 发送中等消息（句柄模式）

**参数**:
- `handle`: `Int` - 内存池句柄

**返回**: `(Scheduler, Bool)`

---

### send_large(scheduler, from, to, handle, access_mode, priority)
**说明**: 发送大消息（共享内存模式）

**参数**:
- `access_mode`: `AccessMode` - 访问模式（ReadOnly/ReadWrite）

**返回**: `(Scheduler, Bool)`

---

### process_one(scheduler)
**说明**: 处理一条消息（按优先级顺序）

**返回**: `Scheduler` - 新调度器

---

### run_loop(scheduler, max_iter)
**说明**: 运行调度循环

**参数**:
- `max_iter`: `Int` - 最大迭代次数

**返回**: `Scheduler`

---

### print_status(scheduler)
**说明**: 打印调度器当前状态

**返回**: `Unit`

---

## MemoryPool API

### create(config)
**说明**: 创建内存池

**参数**:
- `config`: `MemoryPoolConfig` - 配置（块大小和块数量）

**返回**: `MemoryPool`

---

### allocate(memory_pool)
**说明**: 从池分配一个块

**返回**: `(MemoryPool, Option[Int])` - (新池, 块ID或None)

---

### retain(memory_pool, id)
**说明**: 增加块的引用计数

**返回**: `MemoryPool`

---

### release(memory_pool, id)
**说明**: 释放块（引用计数减1，归零回收）

**返回**: `MemoryPool`

---

### free_count(memory_pool)
**说明**: 当前空闲块数量

**返回**: `Int`

---

### allocated_count(memory_pool)
**说明**: 已分配块数量

**返回**: `Int`

---

## RingBuffer API

### create(capacity, default)
**说明**: 创建环形队列

**参数**:
- `capacity`: `Int` - 容量（实际可用capacity-1）
- `default`: `T` - 默认值（预填充用）

**返回**: `RingBuffer[T]`

---

### enqueue(ring_buffer, item)
**说明**: 入队

**返回**: `(RingBuffer[T], Bool)` - (新队列, 是否成功)

---

### dequeue(ring_buffer)
**说明**: 出队

**返回**: `(RingBuffer[T], Option[T])` - (新队列, 项或None)

---

### peek(ring_buffer)
**说明**: 查看队首但不取出

**返回**: `Option[T]`

---

### length(ring_buffer)
**说明**: 当前长度

**返回**: `Int`

---

### is_empty(ring_buffer)
**说明**: 是否为空

**返回**: `Bool`

---

### capacity(ring_buffer)
**说明**: 队列容量

**返回**: `Int`

---

## 数据结构

### ComponentInfo
```moonbit
struct ComponentInfo {
  name: String
  component_type: String
  status: ComponentStatus
}
```

### MemoryPoolConfig
```moonbit
struct MemoryPoolConfig {
  block_size: Int
  block_count: Int
}
```

### Message（枚举）
```moonbit
enum Message {
  SmallMessage(from: Int, to: Int, payload: SmallPayload)
  MediumMessage(from: Int, to: Int, handle: Int)
  LargeMessage(from: Int, to: Int, handle: Int, access_mode: AccessMode)
}
```

### MessagePriority（枚举）
```moonbit
enum MessagePriority {
  High
  Normal
  Low
}
```

### AccessMode（枚举）
```moonbit
enum AccessMode {
  ReadOnly
  ReadWrite
}
```

### ComponentStatus（枚举）
```moonbit

  Created
  Initialized
  Running
  Paused
  Stopped
```
