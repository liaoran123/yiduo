## 1. core 模块（核心基础包）

**位置**: [src/core/](../src/core/)

**职责**: 提供所有高性能基础设施

### 1.1 message.mbt · 消息系统

**位置**: [src/core/message.mbt](../src/core/message.mbt)

**类型**: `Message`（枚举，三种变体）

| 变体 | 模式 | 适用场景 |
|------|------|---------|
| `SmallMessage` | 复制 | 命令、事件（<256B） |
| `MediumMessage` | 句柄 | 传感器数据（256B-64KB） |
| `LargeMessage` | 共享内存 | 图像、大文件（>64KB） |

**优先级枚举**: `MessagePriority::{ High | Normal | Low }`

**访问模式**: `AccessMode::{ ReadOnly | ReadWrite }`

### 1.2 ring_buffer.mbt · 零拷贝环形队列

**位置**: [src/core/ring_buffer.mbt](../src/core/ring_buffer.mbt)

**核心结构**: `RingBuffer[T]`（泛型）

| 字段 | 类型 | 说明 |
|------|------|------|
| `buffer` | `FixedArray[T]` | 裸数组（无 Option 装箱） |
| `capacity` | `Int` | 总容量（实际可用 capacity-1） |
| `read_idx` | `Int` | 读指针 |
| `write_idx` | `Int` | 写指针 |

**关键 API**:

| 函数 | 复杂度 | 说明 |
|------|--------|------|
| `create(capacity, default)` | O(n) | 预分配数组 |
| `enqueue(self, item)` | O(1) | 入队（满时返回 false） |
| `dequeue(self)` | O(1) | 出队（空时返回 None） |
| `length(self)` | O(1) | 当前长度 |
| `is_empty(self)` | O(1) | 判空 |

**性能特点**:
- 无 Option 装箱（原始版本有，优化版本消除）
- 通过 read/write 指针比较判空满
- 浪费一个槽位（容量 = capacity - 1）
- 零拷贝（只移动指针，不移动数据）

### 1.3 memory_pool.mbt · 预分配内存池

**位置**: [src/core/memory_pool.mbt](../src/core/memory_pool.mbt)

**核心结构**: `MemoryPool`

| 字段 | 类型 | 说明 |
|------|------|------|
| `blocks` | `FixedArray[MemoryBlock]` | 内存块数组 |
| `free_stack` | `FixedArray[Int]` | 空闲块索引栈 |
| `free_top` | `Int` | 栈顶指针 |

**关键 API**:

| 函数 | 复杂度 | 说明 |
|------|--------|------|
| `create(config)` | O(n) | 预分配所有块 |
| `allocate(self)` | O(1) | 从栈顶弹出 |
| `retain(self, id)` | O(1) | 引用计数+1 |
| `release(self, id)` | O(1) | 引用计数-1，归零回收入栈 |

**优化对比（优化前 → 优化后）**:

```
优化前: Map[String, MemoryBlock] + List[String] (free)
         ├── 哈希查找 O(1) 但常数大 (~50ns)
         ├── String 分配堆内存
         └── List 遍历

优化后: FixedArray[MemoryBlock] + FixedArray[Int] (栈)
         ├── 直接索引访问 O(1) (~2ns)
         ├── Int 栈上分配（无堆分配）
         └── 栈顶指针 O(1) (~1ns)
```

## 2. scheduler 模块（调度系统）

**位置**: [src/scheduler/](../src/scheduler/)

**职责**: 消息路由、优先级调度、组件管理

### 核心结构: `Scheduler`

| 字段 | 类型 | 说明 |
|------|------|------|
| `high_queue` | `RingBuffer[Message]` | 高优先级队列（64槽） |
| `normal_queue` | `RingBuffer[Message]` | 普通优先级队列（256槽） |
| `low_queue` | `RingBuffer[Message]` | 低优先级队列（128槽） |
| `pool` | `MemoryPool` | 预分配内存池 |
| `components` | `FixedArray[Option[ComponentInfo]]` | 组件表（32槽） |
| `max_components` | `Int` | 最大组件数 |
| `is_running` | `Bool` | 运行状态 |

### 核心 API

| 函数 | 说明 | 关键参数 |
|------|------|---------|
| `create()` | 创建调度器 | - |
| `register(self, info)` | 注册组件 | 返回 Int ID |
| `send_small(self, from, to, payload, priority)` | 发小消息 | from/to 为 Int ID |
| `send_medium(self, from, to, handle, priority)` | 发中消息 | handle 为 Int 索引 |
| `send_large(self, from, to, handle, mode, priority)` | 发大消息 | mode 为 AccessMode |
| `process_one(self)` | 处理一条消息 | 优先级顺序 |
| `run_loop(self, max_iter)` | 运行调度循环 | - |
| `print_status(self)` | 打印状态 | - |

### 调度算法

```
process_one():
  1. 尝试 dequeue high_queue
     → 有消息: dispatch()
     → 无消息: 继续
  2. 尝试 dequeue normal_queue
     → 有消息: dispatch()
     → 无消息: 继续
  3. 尝试 dequeue low_queue
     → 有消息: dispatch()
     → 无消息: 无操作
```

### ComponentInfo 结构

```moonbit
struct ComponentInfo {
  name: String           // 组件名称
  component_type: String // "native" | "wasm" | "moonbit"
  status: ComponentStatus // Created | Initialized | Running | Paused | Stopped | Error
  capabilities: List[String] // 能力列表 ["log", "count", "display"]
}
```

## 5. bootstrap 模块（启动器）

**位置**: [src/bootstrap.mbt](../src/bootstrap.mbt)

**职责**: 系统入口，初始化调度器，加载配置，注册组件

### 启动流程

```
main()
 ├── [1/3] 加载配置
 │   ├── load config
 │   └── validate config
 │
 ├── [2/3] 初始化调度器
 │   ├── create scheduler
 │   ├── 高优队列: 64
 │   ├── 普通队列: 256
 │   ├── 低优队列: 128
 │   ├── 内存池: 64块 × 4KB
 │   └── 组件表: 32槽位
 │
 └── [3/3] 注册组件 + 发送消息
      ├── 注册日志服务 (ID: 0)
      ├── 注册计数器 (ID: 1)
      ├── 注册显示器 (ID: 2)
      ├── 发送小消息（复制模式）
      ├── 发送中消息（句柄模式）
      ├── 发送大消息（共享内存）
      └── 运行调度循环 (10次迭代)
```
