# 一多操作系统架构设计

## 1. 整体架构

一多操作系统采用分层混合架构，利用 MoonBit 语言的双重编译能力（Wasm + Native），在保证系统安全与跨平台性的同时，保留对物理硬件的直接控制力。

### 1.1 核心架构层次

| 层级 | 技术栈 | 运行模式 | 核心职责 | 典型组件 |
|------|--------|----------|----------|----------|
| 应用层 | MoonBit (Wasm) | 沙箱隔离 | 业务逻辑、UI、AI 编排 | 办公套件、AI 助手 |
| 服务层 | MoonBit (Wasm + WASI) | 标准化接口 | 网络、文件、配置管理 | Web 服务器、日志服务 |
| 内核层 | MoonBit (Native) | 特权模式 | 内存管理、进程调度、中断 | 内存管理单元 (MMU) |
| 驱动层 | MoonBit (Native) | 硬件直连 | 硬件驱动、GPU/NPU 接口 | 显卡驱动、NPU 推理引擎 |

### 1.2 关键技术

- **MoonBit**：全栈开发语言，支持 Wasm 和 Native 编译
- **Wasmtime**：WebAssembly 运行时，负责执行 Wasm 组件
- **WASI**：系统接口标准，定义系统服务的接口
- **UniHAL**：统一硬件抽象层，屏蔽底层硬件差异

## 3. 核心组件设计

### 3.1 UniHAL (统一硬件抽象层)

UniHAL 是一多操作系统的核心，它定义了一套面向资源的标准化组件协议，实现了硬件无关性。

#### 3.1.1 核心接口

- **base.wit**：定义基础能力和错误类型
- **memory.wit**：定义内存与存算接口，支持存算一体架构
- **stream.wit**：定义流式设备接口，适用于串口、网卡、存储等
- **unihal.wit**：主接口文件，组合所有接口

#### 3.1.2 适配器层

适配器层负责将 Wasm 的调用翻译成具体的硬件指令，实现硬件无关性：

- **计算适配器**：处理存算缓冲区的创建、数据上传/下载、矩阵运算等
- **流适配器**：处理流设备的打开、读取、写入、刷新等
- **适配器管理器**：根据硬件情况选择合适的适配器

### 3.2 内核层

内核层负责系统的核心功能，包括：

- **内存管理**：物理内存分配、虚拟内存管理
- **进程调度**：进程创建、调度、同步
- **中断处理**：中断响应、处理
- **驱动管理**：硬件驱动的加载、管理

### 3.3 运行时

运行时负责 Wasm 组件的加载和执行：

- **Wasm 加载器**：加载 Wasm 模块
- **Wasm 执行引擎**：执行 Wasm 指令
- **组件管理**：管理 Wasm 组件的生命周期

### 3.4 应用层

应用层是用户与系统交互的界面，包括：

- **用户应用**：办公套件、AI 助手等
- **系统服务**：Web 服务器、日志服务等
- **开发工具**：编译器、调试器等

## 4. 工作流程

### 4.1 系统启动流程

1. **Bootloader 加载内核**：Bootloader 从存储设备加载内核到内存
2. **内核初始化**：内核初始化硬件、内存管理、中断处理
3. **运行时启动**：启动 Wasm 运行时，加载核心服务
4. **应用启动**：加载用户应用，进入用户空间

### 4.2 硬件访问流程

1. **应用请求**：应用通过 UniHAL 接口请求硬件资源
2. **适配器处理**：适配器将请求翻译成具体的硬件指令
3. **硬件操作**：执行硬件操作，获取结果
4. **结果返回**：将结果返回给应用

### 4.3 组件通信流程

1. **接口定义**：通过 WIT 文件定义组件接口
2. **组件实现**：使用 MoonBit 实现组件
3. **组件加载**：Wasm 运行时加载组件
4. **组件调用**：通过接口调用组件功能

## 5. 技术优势

1. **硬件无关性**：通过 UniHAL 实现硬件抽象，支持多种硬件平台
2. **安全性**：Wasm 沙箱隔离，保护系统和用户数据
3. **高性能**：关键路径使用 Native 代码，确保系统性能
4. **可扩展性**：模块化设计，支持动态加载和卸载组件
5. **跨平台**：一次编译，到处运行，支持多种硬件架构
6. **生态兼容性**：支持现有的系统库和第三方库的集成

## 7. 结论

一多操作系统采用分层混合架构，利用 MoonBit 语言的双重编译能力和 Wasm 组件模型，实现了一个安全、高效、跨平台的操作系统。通过 UniHAL 接口和适配器层，实现了硬件无关性，为未来的存算一体架构和多样化的硬件平台提供了良好的支持。
