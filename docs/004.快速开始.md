# 快速开始指南

## 环境准备

### 安装 MoonBit

确保已安装 MoonBit 开发环境：

```bash
# 检查安装
moon --version
```

### WAMR 运行时（可选）

一多 OS 的 Wasm 沙箱运行时采用**组件配置驱动**模式，
用户通过 `configs/bootstrap.yaml` 中的 `runtime.implementation` 控制：

- **wamr-real**: 真实 WAMR，高性能沙箱隔离（需 CMake + git + MinGW）
- **wamr-stub**: 零依赖回退，无外部依赖

## 项目结构

```
yiduo/
├── runtime/                # MoonBit 调度核心
│   ├── bootstrap.mbt       # 启动入口
│   ├── core/               # 核心基础包
│   ├── scheduler/          # 调度系统
│   ├── config/             # 配置解析（递归 YAML 解析器）
│   └── wamr/               # WAMR 运行时集成（动态构建）
├── configs/                # 组件配置（008 规范）
│   ├── bootstrap.yaml      # 自举配置（用户选择实现）
│   └── components/         # 组件定义
│       └── wamr-runtime.yaml  # WAMR 组件（两种实现，包含构建元数据）
├── tools/                  # 自举工具集
│   └── yaml_query/         # 递归 YAML 查询工具（MoonBit 实现）
├── scripts/
│   └── build_wamr.ps1      # 自举构建脚本（读取 YAML → 动态生成 moon.pkg）
└── docs/                   # 技术文档（你在这里）
```

## 开发命令

```bash
# 格式化代码
moon fmt

# 更新接口信息
moon info

# 运行测试（Stub 模式）
moon test --target native

# 构建项目（Stub 模式）
moon build
```

## 启用真实 WAMR

```powershell
# 1. 一键构建 WAMR（读取 bootstrap.yaml 配置，自动判断 real/stub）
.\scripts\build_wamr.ps1

# 2. 运行测试（此时输出应显示 "real mode"）
moon test --target native

# 切换回 Stub 模式
.\scripts\build_wamr.ps1 -Stub
moon test --target native  # 输出显示 "stub mode"
```

验证标准：
- Stub 模式: 控制台输出 `[WAMR] runtime_init() - stub mode, WAMR not yet linked`
- Real 模式: 控制台输出 `[WAMR] 运行时初始化成功 (real mode)`
- 两种模式均 36/36 测试通过

## 自举验证流程

1. **初始化调度器**
2. **注册调度核心（ID 0）**
3. **加载自举配置**
4. **配置驱动注册组件**
5. **测试消息分发**
6. **运行调度循环**

## 常见问题

### moon build 失败

可能是环境配置问题，检查 MoonBit 安装是否完整。

### WAMR 构建失败

确保以下依赖已安装：
- CMake（`cmake --version`）：从 https://cmake.org 安装
- Git（`git --version`）：从 https://git-scm.com 安装  
- MinGW（`gcc --version`）：从 https://www.mingw-w64.org 安装

构建脚本会**自动降级**为 Stub 模式，不会阻塞开发流程。

### 如何选择运行时实现？

编辑 `configs/bootstrap.yaml`：
```yaml
runtime:
  implementation: wamr-real   # 改为 wamr-stub 切换回退模式
```

然后运行 `.\scripts\build_wamr.ps1` 使配置生效。

### 如何添加新组件？

1. 在 config 中添加配置
2. 调用 `scheduler.register()` 注册
3. 获得 Int ID，使用该 ID 通信
