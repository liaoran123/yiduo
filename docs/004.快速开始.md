# 快速开始指南

## 环境准备

### 安装 MoonBit

确保已安装 MoonBit 开发环境：

```bash
# 检查安装
moon --version
```

## 项目结构

```
yiduo/
├── src/                    # 源代码
│   ├── bootstrap.mbt       # 启动入口
│   ├── core/               # 核心基础包
│   ├── scheduler/          # 调度系统
│   ├── config/             # 配置解析
│   └── component/          # 组件管理
├── docs/                   # 技术文档（你在这里）
├── moon.mod.json           # 模块配置
└── moon.pkg                # 包配置
```

## 开发命令

```bash
# 格式化代码
moon fmt

# 更新接口信息
moon info

# 运行测试
moon test

# 构建项目
moon build

# 运行（如果有main函数）
moon run src/bootstrap.mbt
```

## 自举验证流程

1. **初始化调度器**
2. **注册调度核心（ID 0）**
3. **加载自举配置**
4. **配置驱动注册组件**
5. **测试消息分发**
6. **运行调度循环**

## 常见问题

### moon build 失败

可能是环境配置问题，检查 MoonBit 安装是否完整。

### 如何添加新组件？

1. 在 config 中添加配置
2. 调用 `scheduler.register()` 注册
3. 获得 Int ID，使用该 ID 通信
