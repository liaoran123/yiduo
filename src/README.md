# 一多 OS 源代码目录（高性能重构版）

## 目录结构

```
src/
├── bootstrap.mbt      # 最小启动器 (主入口)
├── moon.pkg           # 主包配置 (is-main)
├── core/              # 核心基础包 (高性能基础设施)
│   ├── moon.pkg
│   ├── message.mbt        # 消息系统（三种模式）
│   ├── ring_buffer.mbt    # 零拷贝环形队列
│   └── memory_pool.mbt    # 预分配内存池
├── scheduler/         # 调度系统核心 (高性能版)
│   ├── moon.pkg
│   └── scheduler.mbt
├── config/            # 配置解析模块
│   ├── moon.pkg
│   └── config_loader.mbt
└── component/         # 组件管理模块
    ├── moon.pkg
    └── loader.mbt
```

## 模块说明

### 1. bootstrap.mbt
一多 OS 的最小启动器，负责：
- 加载配置文件
- 初始化高性能调度系统
- 注册组件
- 发送测试消息（三种模式）
- 启动调度循环

### 2. core/（新增！高性能基础设施）
核心基础包，提供高性能调度所需的基础设施：

- **message.mbt**：消息系统（三种模式）
  - 小消息（复制模式，<256B，安全优先）
  - 中消息（句柄模式，平衡）
  - 大消息（共享内存模式，性能优先）
  - 三种优先级（高/普通/低）
- **ring_buffer.mbt**：零拷贝环形队列
  - 固定容量预分配
  - 入队/出队只移动指针，不复制数据
  - 支持泛型
- **memory_pool.mbt**：内存池系统
  - 启动时预分配内存块
  - 引用计数管理
  - 分配/释放效率高

### 3. scheduler/
调度系统核心（高性能重构版），负责：
- 零拷贝环形队列（三个优先级独立队列）
- 三种消息模式分发
- 内存池管理
- 组件注册和状态管理
- 优先级调度（高 > 普通 > 低）

### 4. config/
配置解析模块，负责：
- 解析 YAML/JSON 配置文件
- 验证配置完整性
- 提供配置数据结构

### 5. component/
组件管理模块，负责：
- 发现组件
- 加载 Wasm/Native/MoonBit 组件
- 管理组件生命周期

## 性能特性

| 特性 | 旧版本 | 重构版 |
|------|--------|--------|
| 队列 | 简单 List | 零拷贝环形队列 |
| 消息传递 | 假设函数调用 | 三种混合模式 |
| 内存管理 | 动态分配 | 预分配内存池 |
| 调度 | 简单顺序 | 优先级调度 |

## 构建和运行

```bash
# 格式化代码
moon fmt

# 更新接口信息
moon info

# 运行测试
moon test

# 构建项目
moon build
```

## 架构理念（四元架构）

- **意志**：配置文件表达用户意图
- **DNA**：组件作为系统的基本单元
- **树形**：配置的层级结构
- **链式**：组件之间的依赖和调用关系
