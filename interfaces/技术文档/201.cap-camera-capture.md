# Camera Capture 接口文档

## 概述

`cap/camera/capture.wit` 定义了摄像头图像捕获能力。这是一多 OS 中"能力积木"理念的典型示例——小而专一的能力。

WIT 文件位置：[../cap/camera/capture.wit](../cap/camera/capture.wit)

**相关接口**：
* [cap-camera-config（202.cap-camera-config.md）](./202.cap-camera-config.md) - 摄像头配置
* [cap-camera-stream（203.cap-camera-stream.md）](./203.cap-camera-stream.md) - 摄像头视频流
* [cap-camera-info（204.cap-camera-info.md）](./204.cap-camera-info.md) - 摄像头信息

## 核心类型

### image (图像数据)

```wit
type image = list<u8>
```

**说明**：原始图像数据缓冲区，包含完整的图像像素数据。

**格式约定**：
* 默认图像格式为 **RGB 24-bit**（R, G, B 各 8 位）
* 如果需要其他格式，通过 [cap-camera-config](./202.cap-camera-config.md) 接口配置
* 数据是像素顺序排列，从左到右，从上到下
* 图像尺寸由 [cap-camera-info](./204.cap-camera-info.md) 获取

**数据布局**（示例 640x480 图像）：
```
offset 0000: R(0,0), G(0,0), B(0,0), R(1,0), G(1,0), B(1,0), ...
offset 1920: R(0,1), G(0,1), B(0,1), R(1,1), G(1,1), B(1,1), ...
...
```

## 接口函数

### capture (捕获单张图像)

#### 签名
```wit
capture: func() -> result<image, Error>;
```

#### 说明
从摄像头捕获一帧图像并返回原始图像数据。

#### 参数
无参数

#### 返回值
* **成功时**：返回包含原始图像数据的 `image` 类型
* **失败时**：返回相应的 `Error` 错误码

#### 错误码
| 错误码 | 说明 | 常见场景 |
|-------|------|---------|
| `Success` | 捕获成功 | 正常情况 |
| `IoError` | 硬件 IO 错误 | 摄像头断开、通信失败 |
| `Timeout` | 捕获超时 | 摄像头响应缓慢 |
| `NotSupported` | 功能不支持 | 摄像头不支持图像捕获 |
| `InternalError` | 内部错误 | 驱动或系统错误 |
| `OutOfMemory` | 内存不足 | 无法分配足够内存 |

#### 示例代码
```
// 简单捕获图像
let capture-result = camera-capture.capture()

if capture-result.err == Error.Success {
  let image-data = capture-result.ok
  // 处理图像数据
  process-image(image-data)
} else {
  println("捕获失败，错误码：" + to-string(capture-result.err))
}
```

## 使用示例

### 场景 1：单次拍照并保存
```
fn take-photo() {
  println("开始拍照...")
  
  // 捕获图像
  let capture-result = camera-capture.capture()
  
  if capture-result.err != Error.Success {
    println("拍照失败：" + to-string(capture-result.err))
    return
  }
  
  let photo = capture-result.ok
  
  // 获取图像信息（从 info 接口）
  let (width, height) = camera-info.get-resolution()
  
  println("拍照成功，尺寸：" + width + "x" + height)
  
  // 保存到文件
  save-image-to-file(photo, "photo.jpg")
}
```

### 场景 2：连拍多张照片
```
fn burst-shot(count: int) {
  let photos: list<image> = list.empty()
  
  for i in 0..count {
    let result = camera-capture.capture()
    if result.err == Error.Success {
      photos.push(result.ok)
      println("第 " + i + " 张拍照成功")
    } else {
      println("第 " + i + " 张拍照失败：" + to-string(result.err))
    }
  }
  
  println("共成功捕获 " + photos.length() + " 张照片")
}
```

### 场景 3：带重试机制的捕获
```
fn capture-with-retry(max-tries: int) -> result<image, Error> {
  let last-error = Error.Success
  
  for attempt in 0..max-tries {
    println("尝试第 " + attempt + " 次捕获...")
    
    let result = camera-capture.capture()
    
    if result.err == Error.Success {
      return result // 成功，直接返回
    }
    
    last-error = result.err
    
    // 如果是超时，可以重试
    if result.err == Error.Timeout {
      println("超时，等待后重试...")
      sleep(100) // 等待 100ms
      continue
    }
    
    // 其他错误，直接失败
    break
  }
  
  // 所有尝试都失败
  return result-with-error(last-error)
}
```

## 最佳实践

### 1. 配合配置使用
* 在调用 capture 前，应该先用 [cap-camera-config](./202.cap-camera-config.md) 配置好参数
* 特别是分辨率、格式等关键参数
* 配置好之后再开始捕获

### 2. 处理图像数据
* image 是原始二进制数据，需要根据配置的格式解析
* 对于大分辨率图像，注意内存占用
* 如果不需要处理所有像素，可以考虑裁剪

### 3. 性能优化
* capture 是同步操作，会阻塞当前线程
* 如果在 UI 线程调用，可能会导致界面卡顿
* 考虑在后台线程执行 capture

### 4. 错误处理
* 注意捕获超时的情况，设计重试机制
* IO 错误可能表示硬件断开，需要重新初始化
* 内存不足时，考虑降低分辨率

### 5. 资源管理
* capture 可能会消耗大量资源
* 确保在不需要时释放相关资源
* 如果是 Native 实现，确保没有内存泄漏
