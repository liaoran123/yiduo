## 📖 详细步骤：编译 Rust Wasm 组件

按照 [调用 Rust 的 Wasm 组件示例](./019.调用Rust的Wasm组件示例.md) 的步骤：

### 前提条件

需要安装：
1. **Rust**（包含 cargo）
2. **MoonBit**（如果需要）
3. **wit-bindgen-cli**
4. **wasm-tools**
5. **Wasmtime**

---

### 步骤 1：编译 Rust 组件

在 `components/impl/rust-hello/` 目录：

```bash
cd d:\yiduo\components\impl\rust-hello
```

首先运行 `wit-bindgen` 生成绑定代码（需要先取消 lib.rs 中的注释）：

```bash
wit-bindgen rust ../../../interfaces/base/hello.wit --out-dir src
```

然后修改 `src/lib.rs`，取消注释真实的实现代码。

最后编译：

```bash
rustup target add wasm32-wasip1
cargo build --target wasm32-wasip1 --release
```

---

### 步骤 2：转换为标准 Wasm Component

```bash
cd d:\yiduo\components\impl\rust-hello
wasm-tools component embed ../../../interfaces/base/hello.wit target/wasm32-wasip1/release/rust_hello.wasm -o hello_world.embed.wasm
wasm-tools component new hello_world.embed.wasm -o ../../hello-world.wasm
```

---

### 步骤 3：测试 Wasm 组件

```bash
cd d:\yiduo\components
wasmtime run hello-world.wasm
```
